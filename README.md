# Asphyxia EA3 Uploader

Provides uploader module not included in [Asphyxia CORE](https://asphyxia-core.github.io/).

Made for [Asphyxia LPAC Plugin](https://github.com/Cetaceaqua/asphyxia-lpac-plugin), and can also be integrated into other Asphyxia plugins easily.

However, you should add the uploader feature directly to CORE to better support all games that use this feature.
